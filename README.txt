EV Raster Crafts by EVORA - build folder
========================================
Requirements (Windows): Node.js 18+, Rust (rustup.rs), internet access.

Build:   double-click build.bat   (or run: node build-installer.js)
Output:  dist\EV_Raster_Crafts_Setup.exe  (give to other PCs; double-click to install)
         The build also registers the "ev_raster_crafts" server with Claude Desktop on this PC.

Afterwards: fully quit and restart Claude Desktop.
Test: "Use EV Raster Crafts to draw a red heart on a blue background and show the canvas."
